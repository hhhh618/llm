# 六类修学：检索依据与使用边界

这些入口主要是巴利经典英译及藏译大乘经典英译；不代表所有传统的唯一解释。根据用户所问引用具体经典，不把现代微行动冒充经文原话。需要比较宗派或细节有争议时，说明版本、语境及不确定性；优先寻找用户所用传统的原典和可靠译本。

## 三皈五戒

- 方向：皈依佛、法、僧；五戒为不杀生、不偷盗、不邪淫、不妄语、不饮酒等令人放逸的醉品。僧宝在经典中常指圣弟子僧，僧团亦有出家团体的含义，不能只说成普通朋友。遵循不同传统对戒相的解释。
- 依据：[增支部 AN 8.39](https://accesstoinsight.org/tipitaka/an/an08/an08.039.than.html)，巴利传统，将三皈与五戒并列；可用于说明自愿学习的伦理方向。
- 微行动：例如在一场谈话前停一下，选择真实且不伤人的表达。生活练习不等同正式皈依或受戒。

## 十善及“上品”

- 身：不杀、不盗、不邪淫；口：不妄语、不两舌、不恶口、不绮语；意：无贪、无嗔、正见。不同传统解释和用语略有差异；不可把在家人的不邪淫普遍说成完全禁欲，也不将意三等同已经彻底断尽烦恼。
- 依据：[增支部 AN 10.176](https://accesstoinsight.org/tipitaka/an/an10/an10.176.than.html)，巴利传统，列举十种善业道；它并非“上品”分级的依据。若用户问上品的严格标准，应查明所依经典或论典，不把主动善行直接定义为上品。
- 微行动：依实际条件选择护生、适度布施、少说伤人话。放生不必作为默认建议，避免购买、放养外来种或误放造成伤害。

## 四禅与四无色定

- 依据：[增支部 AN 9.36](https://accesstoinsight.org/tipitaka/an/an09/an09.036.than.html)，巴利传统，讨论四禅、无色定与观照；它不是给初学者自行速成的指南。各传统对禅定的解释及教学方式不同。
- 初学者短暂注意呼吸、接触地面或环境，是基础安住练习，不能称作达到某禅。四禅的舍念清净不等于思想彻底消失；无色定中超越对色相的知觉不等于已断一切执著或已解脱。

## 四圣谛

- 依据：[中部 MN 141](https://accesstoinsight.org/tipitaka/mn/mn.141.than.html)，巴利传统，说明苦、集、灭、道及八正道。八支互相支持，不简化为只有正见和正定重要。苦的范围比情绪困扰广；灭不等于承诺身体疾病或生活中一切不适消失。
- 可用来整理“现在的困扰、可能助长它的条件、希望减少什么、可尝试的行动”，这是现代应用，并非心理诊断或经文逐字翻译。

## 十二因缘

- 依据：[相应部 SN 12.2](https://accesstoinsight.org/tipitaka/sn/sn12/sn12.002.than.html)，巴利传统，列出和解释十二支条件关系。教理涉及生死流转，不应被简化为仅是一次情绪事件。
- 可用“发生了什么接触—感受如何—有什么想抓住或推开的冲动—如何执取”做生活观察，明确这是简化的应用，而非唯一的修行切入处，也不保证阻止贪爱生起。

## 六度万行

- 依据：[《妙臂所请经》Toh 70，1.3–1.4 等](https://84000.co/translation/toh70)，大乘经典，列举布施、持戒、忍辱、精进、禅定、智慧并详细说明。般若统摄诸度是大乘语境中的重要解释；勿由此断言其他传统不能解脱。[《十千颂般若波罗蜜多经》](https://84000.co/translation/984546d9-78c4-41df-bca0-88ad42870619?main=open%3Afront%3A92f9f5b2-681e-4955-88a0-6c8adffe8808)说明诸度相摄。
- 日常可从不超出自身能力的善意行动或清晰表达界限开始；利他不要求牺牲人身安全、经济基本需要或承担他人的全部责任。

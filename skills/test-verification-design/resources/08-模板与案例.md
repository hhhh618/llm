## 4. 指标输出模板

按[07](07-指标与计算.md)先锁定口径，使用 `python3 scripts/metrics.py --input data.json`；也可从标准输入提供JSON。输出解释至少保留：

## 5. 案例一：工程研制阶段快速选项

**输入（合成）：** 某软件密集分系统，工程研制阶段，承制方，BIT结合ATE。请求提出工作项目清单；尚未提供合同完整项目要求和验证判据。

**处理：** 读取02的5.2和资料性表A.1，再按01的软件测试性和03/04/05映射输入输出。形成建议清单：202细化合同任务；301~307支撑方案、模型、分配、预计、准则、诊断、核查；401/402按实物可试验性和要求覆盖组织验证；403按阶段数据条件判断。101/102及201由订购方主导形成上游依据，承制方参与协调；203~206按实际职责和合同组织。501/502属于后续使用工作，可提前安排其数据接口，不能写成当前必须全部完成。

**输出：** 给出剪裁表、缺失合同/方案/故障模式/验证判据清单和责任接口。标“工程建议，待合同确认”，不把矩阵的√当所有项目的无条件必选。来源：02正文5.2 PDF12；资料性A.3 PDF27~28；01正文4.9 PDF10~11。

## 7. 案例三：计算正确但证据不足

**输入（合成、明确逐条报警映射）：** 责任故障100次，正确检测90次，在规定LRU且模糊度≤1条件下正确隔离72次；全部报警120次，确认虚警30次。用户问是否可据附录示例判合格。

可运行输入：

```json
{
  "mode": "count_assessment",
  "metrics": ["FDR", "FIR", "FAR"],
  "isolation_unit": "现场可更换单元 LRU",
  "max_ambiguity": 1,
  "isolation_scope_confirmed": true,
  "alarm_fault_mapping": "one_alarm_per_detected_fault",
  "counts": {"faults": 100, "detected": 90, "isolated": 72, "alarms": 120, "false_alarms": 30}
}
```

**结果：** FDR=90/100×100%=90%；FIR=72/90×100%=80%；FAR=30/120×100%=25%。FIR不能算成72/100。以上均为计数点估计，脚本返回“未判定”及没有已计算置信限。

**处理与输出：** 附录表A.3的示例不是合同门限；正文8.3.2.7一般要求FDR/FIR用单侧置信下限、FAR用单侧置信上限。没有合同判据、置信水平和已认可的样本/统计方案时，只能报告上述点估计和证据不足，不能判合格。来源：07资料性A.7.2.3.9 PDF57，05正文8.3.2.7 PDF24，02资料性表A.3 PDF33。

## 8. 案例四：加权预计与计数不同

**输入（合成）：** 三个故障模式故障率为0.002、0.001、0.001 (1/h)，前两项可检测；第一项可唯一隔离，第二项隔离模糊度2；第三项不可测。当前统计范围为LRU、要求模糊度≤1，并已人工确认隔离分类。

```json
{
  "mode": "weighted_prediction",
  "metrics": ["FDR", "FIR"],
  "failure_rate_unit": "1/h",
  "isolation_unit": "现场可更换单元 LRU",
  "max_ambiguity": 1,
  "isolation_scope_confirmed": true,
  "faults": [
    {"id": "f1", "failure_rate": 0.002, "detected": true, "isolation_ambiguity": 1},
    {"id": "f2", "failure_rate": 0.001, "detected": true, "isolation_ambiguity": 2},
    {"id": "f3", "failure_rate": 0.001, "detected": false}
  ]
}
```

预计FDR=(0.002+0.001)/0.004=75%；预计FIR=0.002/0.003≈66.67%。直接数“2个可测/3个故障”得到66.67%不能替代本例加权FDR。来源：07资料性A.6.2.4.4、式A.1/A.3/A.4，PDF48~49。结果用于设计分析，不自动产生试验/评估合格结论。

## 9. 常见问法

- **“FDR多少才合格？”** 先定位合同/研制总要求和验证判据。表A.3仅是示例。
- **“所有项目都得做吗？”** 按要求、产品及阶段剪裁，留理由与约定；不机械全选或全删。
- **“CND都算虚警吗？”** 不可以；需分析间歇故障、BIT、容差、检查及维修记录，见06。
- **“为什么引用PDF48而不是43？”** 48是封面开始计的PDF页，43是印刷正文页。本包明确使用PDF页。
- **“能否给出GJB8895最小样本量？”** 本包不含该引用标准全文，需取得适用版本及认可方案后处理。
- **“怎样查304？”** 运行 `python3 scripts/lookup.py --item 304`，再读返回资源的7.4/A.6.2.4段。

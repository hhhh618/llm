# Knowledge maintenance

When updating this repository:

1. Inspect the existing knowledge files first.
2. Remove transient details and sensitive data.
3. Keep one topic per file.
4. Prefer additions or focused edits over broad rewrites.
5. Run a secret check and review the diff before committing.

# Agent 工作流

将用户目标转成可验证的交付，用执行证据决定流程的复杂度。采用这条决策顺序：

**验收定义 → 单 Agent 基线 → 工具与上下文优化 → 状态恢复 → 按需并行 → 持续评测**

六阶段按需要使用，可以合并、跳过已有证据满足的步骤；它们不是六个 Agent，也不要求生成六套文档。

## 先确定本次工作

- **设计：**形成最简单可行的流程、契约、验证方法；只有用户要求实施时才建设运行系统。
- **诊断 / 局部改进：**还原现有链路，读取失败样本和约束，优先修复有证据的瓶颈，保留用户指定的框架与架构。
- **评测：**比较明确的候选与基线，报告样本、预算、结果和限制；不为制造比较而重建系统。
- **执行复杂任务：**沿用宿主已有工具和工作方式，完成任务并保存所需证据。

用户明确调用技能处理小任务时，直接做最小修改并核验；无需规划多 Agent、持久化系统或评测工程。先利用已有上下文推进，只对影响目标、验收或授权的关键缺口澄清。

## 1. 定义验收

用简短契约写清目标、范围、产物、可观察成功条件、关键约束与预算。沿用已有需求和测试；把未确认的标准标成假设。

区分三个完成层次：产物已生成、外部动作已执行、结果已验证。研究核验来源支持度；代码核验运行行为；业务操作核验远端状态。设计与诊断任务交付的是方案或结论，不把未实施的建议写成已运行结果。

需要契约、评分与用例模板时，读取 [验收与评测](references/acceptance-and-evaluation.md)。

## 2. 建立单 Agent 基线

选择能满足目标的最简单实现：单次调用、固定步骤、单 Agent 工具循环。明确控制流由程序还是模型决定，以及最终由谁交付。

现有单 Agent 结果可直接作为基线。用户指定多 Agent 时保留该选择，使用可获得的基线评估收益；没有可运行基线时说明比较受限，不宣称效果已提升。不要为了基线执行有副作用的生产任务。

## 3. 优化工具与上下文

先检查工具歧义、参数错误、无关数据、缺失事实和过长历史。工具围绕真实任务设计，返回可用结果、明确错误和必要回执；已知身份与业务约束由程序校验。

给每步必要的规则、事实及产物引用，按需读取原始材料。将已验证事实、假设、计划与未解决问题分开；摘要用于导航，保留关键证据的定位方式。

需要接口、状态或错误分类细节时，读取 [执行与恢复](references/execution-and-recovery.md)。

## 4. 按任务需要支持状态恢复

跨会话、长任务、人审等待和外部写入才需要相应的持久化与恢复设计；短只读任务可沿用当前运行状态。

保存步骤、产物引用、验证结果、待办及等待原因。区分暂时失败、可修正输入、缺少信息、权限不足和外部动作结果未知。

外部动作超时不能直接当成失败重做。先查询远端状态；或确认下游支持以稳定操作身份去重后，再决定重试。checkpoint 不保证副作用只发生一次。达到约定预算或相同失败不再产生新信息时停止该重试路径，交付证据与待解决项。具体恢复语义依所用运行时核对，不混淆恢复、重试与调试回放。

## 5. 按需并行

存在独立工作、上下文隔离、工具权限隔离或可验证的独立复核收益时，考虑专家分工。权限隔离须由宿主或工具实际实施，角色分工本身不形成权限边界。按用户选择及宿主可用能力实施；不可用时用顺序步骤表达同样分工。

每次委派明确问题、输入、边界、输出、证据、预算和验收人。独立读操作可以并行；共享资源写入需明确所有权、合并点和冲突处理。主负责人检查子任务结果后交付。

需要委派模板或模式选择时，读取 [按需并行](references/parallelism.md)。

## 6. 持续评测并交付

按风险核验结果、过程约束、重复可靠性和运营成本。优先程序化检查；开放质量使用有具体标准、经过人工校准的判断。允许多条有效工具路径。

比较方案时使用同一任务集与可比预算，记录模型、prompt、工具、上下文和流程版本。将真实失败加入回归集。模型升级或增加组件后，用比较验证是否值得保留。

一次性任务做必要验证即可；只有需要长期运行和迭代的系统才建设持续评测。未能运行的检查写成待验证，不编造评分或通过状态。

## 完成时交付什么

按本次任务给出足够信息即可，不固定报告格式：

- 产物、流程设计或实际改动，以及采用该复杂度的原因。
- 验收证据、比较结果和所用版本；明确实际执行与方案建议。
- 未完成项、未知结果、剩余预算约束与下一步验证。

设计模式需要解释权衡；实施模式需要验证行为。阶段跳过或沿用已有能力时，仅在影响判断时说明原因。敏感外部动作遵守当前任务授权，技能与恢复机制本身不扩展权限。

需要追溯方法依据或更新具体运行时用法时，参阅 [一手来源与适用边界](references/sources.md)；无需每次加载。

# Workflows

## Change workflow

1. Inspect the current state.
2. State assumptions and identify risks.
3. Make the smallest reversible change.
4. Verify behavior proportionally to the risk.
5. Record the result in Git when it is durable project knowledge.

## Knowledge workflow

1. Extract reusable facts from a completed task.
2. Remove secrets, identifiers, and incidental transcript details.
3. Put the fact in the smallest appropriate file.
4. Add a date or confidence note when the fact can change.

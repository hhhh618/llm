# Working preferences

- Prefer concise, evidence-backed communication.
- Preserve existing user changes and avoid destructive operations.
- Use Git for durable project changes.
- Keep secrets and private records outside the repository.
- Verify external, current, or high-impact facts before relying on them.
- In design work, clarify core concepts and context boundaries, and preserve
  conceptual integrity across requirements, models, interfaces, code, and tests.
- Establish scoped domain language before US–AC–TC; use semantic names and
  durable references, and turn repeatable methods into executable workflows,
  subagent task contracts, and skills.
